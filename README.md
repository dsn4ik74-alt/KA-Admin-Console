## Начать работу

1. Скачайте **ZIP** по кнопке выше и распакуйте EXE — устанавливать Python не требуется.
2. Запустите EXE и подтвердите запрос прав администратора.
3. Выберите раздел и укажите параметры подключения к вашему серверу.

## Возможности

| Раздел | Что можно сделать |
| --- | --- |
| **1С** | Найти и открыть базу, добавить её в кластер, опубликовать на IIS/Apache, установить платформу и конфигурации из ИТС, архивировать ЖР, проверить программные лицензии через ring. |
| **СУБД** | Создать или удалить базу, выполнить бэкап, восстановление или цепочку «бэкап + восстановление» для MSSQL и PostgreSQL. |
| **Windows / Linux** | Управлять службами Windows, создавать локальные учётные записи, анализировать диски и передавать файлы через Robocopy, SMB и SFTP. |
| **Планировщик** | Запускать последовательности действий по расписанию и просматривать журналы. |

Есть избранные подключения, параллельные задачи, история операций и сохранённые логи.
Для ИТС нужна ваша учётная запись с доступом к выбранному дистрибутиву; для серверных операций — соответствующие права.

## Что изменилось

**20.33.29** — рабочие вкладки открываются сверху, как в браузере. Каждый щелчок по действию слева создаёт новую форму; верхние вкладки переключаются, закрываются и перетаскиваются. Выполняющиеся задачи отмечаются зелёной точкой. Старые дополнительные пункты слева переносятся наверх. В Releases теперь ZIP с максимальным стандартным сжатием, внутри только EXE.

**20.33.28** — вкладка **«1С → Лицензии 1С · ring»**: список, сведения, поиск, проверка выбранных или всех программных лицензий. Локально в Windows, удалённо Windows (WinRM + SMB) и Linux x86-64 (SSH). Ring, License Tools и отдельная Java встроены; временный комплект на сервере удаляется после проверки. Активация и изменение лицензий не выполняются. Свободные места, HASP и подписка ИТС этой утилитой не определяются.

**20.33.27** — исправлена фоновая ошибка при быстром закрытии окна выбора «Предприятие / Конфигуратор».

**20.33.26** — при открытии базы из «ИБ» можно выбрать «Предприятие» или «Конфигуратор». Подбирается клиент фактической версии кластера; тонкий клиент используется только для «Предприятия». Выделение текста адресов баз стало темнее.

**20.33.25** — новая ИБ из CF создаётся и заполняется сразу в выбранном кластере 1С, без временной файловой базы и выгрузки DT. Для существующей ИБ сохранена полная замена пустым DT. В журнале видны отдельные этапы и состояние регистрации при ошибке лицензии.

**20.33.24** — кнопка **«Проверить SSH»** отдельно у источника и получателя передачи файлов. Успешное подключение сохраняется в списке Linux-серверов. Перед установкой PostgreSQL можно настроить `pg_hba.conf` понятными правилами: базы, пользователи, IP/подсети, разрешения и запреты, порядок проверки и SSL; рядом виден итоговый файл.

**20.33.23** — публикация ИБ на IIS/Apache, управление сайтами, пулами и привязками IIS, редактор конфигураций с резервными копиями. Передача файлов Windows ↔ Windows, Windows ↔ Linux и Linux ↔ Linux; инструкции по включению WinRM, SMB и SSH. Исправлен поиск библиотек PostgreSQL при установке бинарного комплекта Linux в выбранную папку; добавлены проверка запуска утилит и повторное использование совпадающего комплекта после сбоя.

**20.33.22** — разделы и вложенные вкладки перенесены в компактную боковую панель: раскрытие при наведении, перетаскивание, добавление своих разделов и вкладок.

**20.33.21** — светлый интерфейс, карточки главной, фиолетовые акценты и обновлённые таблицы и формы.
