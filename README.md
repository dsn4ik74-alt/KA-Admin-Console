## Начать работу

1. Скачайте **EXE** по кнопке выше — устанавливать Python не требуется.
2. Запустите приложение и подтвердите запрос прав администратора.
3. Выберите раздел и укажите параметры подключения к вашему серверу.

## Возможности

| Раздел | Что можно сделать |
| --- | --- |
| **1С** | Найти и открыть базу, добавить её в кластер, установить платформу и типовые конфигурации из ИТС, архивировать ЖР. |
| **СУБД** | Создать или удалить базу, выполнить бэкап, восстановление или цепочку «бэкап + восстановление» для MSSQL и PostgreSQL. |
| **Windows / Linux** | Управлять службами Windows, создавать локальные учётные записи, анализировать диски Windows и Linux по SSH. |
| **Планировщик** | Запускать последовательности действий по расписанию и просматривать журналы. |

Есть избранные подключения, параллельные задачи, история операций и сохранённые логи.
Для ИТС нужна ваша учётная запись с доступом к выбранному дистрибутиву; для серверных операций — соответствующие права.

## Что изменилось

**20.33.20** — на вкладке «Шаблоны» основная кнопка **«Добавить базу на сервер»** сразу открывает параметры загрузки выбранной конфигурации.

**20.33.19** — во вкладке «ИБ» виден адрес `Srvr="сервер:порт";Ref="база";`. Исправлено извлечение ERP.Управление холдингом: отсутствующий мультиязычный шаблон не мешает обычной и демобазе.

**20.33.18** — отдельные параллельные вкладки бэкапа и восстановления, журналы на главной, необязательная проверка бэкапа MSSQL и обработка журнала базы назначения после восстановления.
