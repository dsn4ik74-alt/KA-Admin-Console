## Начать работу

1. Скачайте **ZIP** по кнопке выше и распакуйте EXE — устанавливать Python не требуется.
2. Запустите EXE и подтвердите запрос прав администратора.
3. Выберите раздел и укажите параметры подключения к вашему серверу.

## Возможности

| Раздел | Что можно сделать |
| --- | --- |
| **1С** | Найти и открыть базу, добавить её в кластер, опубликовать на IIS/Apache, установить платформу и конфигурации из ИТС, архивировать ЖР, проверить программные лицензии через ring. |
| **СУБД** | Создать или удалить базу, выполнить бэкап, восстановление или цепочку «бэкап + восстановление» для MSSQL и PostgreSQL. |
| **Windows / Linux** | Управлять службами Windows, создавать локальные учётные записи, анализировать диски и передавать файлы через Robocopy, SMB и SFTP. |
| **Планировщик** | Запускать последовательности действий по расписанию и просматривать журналы. |

Есть избранные подключения, параллельные задачи, история операций и сохранённые логи.
Для ИТС нужна ваша учётная запись с доступом к выбранному дистрибутиву; для серверных операций — соответствующие права.

## Что изменилось

**20.33.39**

- Добавлена кнопка **«Обновить приложение»**: проверка релиза, загрузка патча, проверка и перезапуск с сохранением настроек.
- Патч переносит только изменившиеся части EXE. Если для установленной версии его нет, полный ZIP скачивается только после подтверждения.
- Исходники перенесены в [`src`](src), чтобы корень репозитория оставался компактным.

Для перехода со старой версии без кнопки обновления один раз скачайте ZIP. Патчи применяются из приложения начиная с этой версии.

**20.33.38**

- Новое оформление стало основным: компактные разделы слева, обновлённые кнопки, поля и таблицы, параметры задачи в отдельной панели. Старое оформление удалено.
- Верхние вкладки закруглены и сжимаются по ширине окна. При переходе из меню используется уже открытая свободная вкладка; если в ней идёт задача, открывается дополнительная.
- Размер создаваемого PostgreSQL-бэкапа обновляется без открытия папки в Проводнике, включая формат `pgdir`.
- Во вкладке ИБ можно перейти в кластер выбранной базы через контекстное меню.
