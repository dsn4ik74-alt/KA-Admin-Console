## Начать работу

1. Скачайте **ZIP** по кнопке выше и распакуйте EXE — устанавливать Python не требуется.
2. Запустите EXE и подтвердите запрос прав администратора.
3. Выберите раздел и укажите параметры подключения к вашему серверу.

## Возможности

| Раздел | Что можно сделать |
| --- | --- |
| **1С** | Найти и открыть базу, управлять пользователями, добавить базу в кластер, опубликовать на IIS/Apache, установить платформу и конфигурации из ИТС, архивировать ЖР, проверить программные лицензии через ring. |
| **СУБД** | Создать или удалить базу, выполнить бэкап, восстановление или цепочку «бэкап + восстановление» для MSSQL и PostgreSQL. |
| **Windows / Linux** | Управлять службами Windows, создавать локальные учётные записи, анализировать диски и передавать файлы через Robocopy, SMB и SFTP. |
| **Планировщик** | Запускать последовательности действий по расписанию и просматривать журналы. |

Есть избранные подключения, параллельные задачи, история операций и сохранённые логи.
Для ИТС нужна ваша учётная запись с доступом к выбранному дистрибутиву; для серверных операций — соответствующие права.

## Что изменилось

**21.1**

- Исправлено закрытие карточек пользователей и свойств публикаций вместе с их рабочей вкладкой.

- Управление пользователями 1С: выбор одной или нескольких баз, создание, изменение, удаление, группы доступа БСП и роли платформы. Для неподдерживаемых конфигураций — переход в Конфигуратор.
- Публикации IIS/Apache: поиск, ссылки с именем сервера, свойства базы и платформы, настройки WS/HS, просмотр каталогов и снятие публикации. Для IIS — преобразование в приложение и исправленное управление пулами.
- Выбор службы из списка при переименовании и удалении. Переход из ИБ в родную консоль 1С (MMC).
- Поиск с `*`: `bp*` — начинается с bp, `*bp*` — содержит bp. Колесо мыши больше не меняет значения выпадающих списков.

**Переход с 20.33.x:** один раз скачайте ZIP и замените EXE. Версия 21.1 поддерживает новый короткий формат номеров для последующих обновлений.
