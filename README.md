## Начать работу

1. Скачайте **ZIP** по кнопке выше и распакуйте EXE — устанавливать Python не требуется.
2. Запустите EXE и подтвердите запрос прав администратора.
3. Выберите раздел и укажите параметры подключения к вашему серверу.

## Возможности

| Раздел | Что можно сделать |
| --- | --- |
| **1С** | Найти и открыть базу, управлять пользователями, добавить базу в кластер, опубликовать на IIS/Apache, установить платформу и конфигурации из ИТС, архивировать ЖР, проверить программные лицензии через ring. |
| **СУБД** | Создать или удалить базу, выполнить бэкап, восстановление или цепочку «бэкап + восстановление» для MSSQL и PostgreSQL. |
| **Windows / Linux** | Управлять службами Windows, создавать локальные учётные записи, анализировать диски и передавать файлы через Robocopy, SMB и SFTP. |
| **Планировщик** | Запускать последовательности действий по расписанию и просматривать журналы. |

Есть избранные подключения, параллельные задачи, история операций и сохранённые логи.
Для ИТС нужна ваша учётная запись с доступом к выбранному дистрибутиву; для серверных операций — соответствующие права.

## Что изменилось

**21.8**

- ПКМ по базе → «Сведения о конфигурации»: ввод пользователя и пароля этой ИБ, проверка и обновление результата в открытом окне и таблице.
- Во вкладке «ИБ» доступны общий логин и пароль и кнопка «Проверить все ИБ с этими данными». Она проверяет все полученные базы независимо от текущего выделения.
- Реквизиты отдельной проверки не изменяют общие поля. Пароли хранятся только в памяти; ошибки подключения отображаются без паролей, доступны исправление реквизитов и повторная проверка.

Для проверки с пользователем ИБ используется внешнее соединение 1С; на компьютере консоли нужен соответствующий компонент той же версии платформы. Сохраняется режим проверки только через кластер: свежие сведения в нём доступны с 8.5.4, на старых платформах используется кеш с датой последней проверки.

**Переход с 20.33.x:** один раз скачайте ZIP и замените EXE. Для 21.x доступно обновление через приложение.

**Переход с 21.4 и ниже:** закройте все экземпляры КА, скачайте актуальный ZIP через браузер и распакуйте EXE в новую папку. Это нужно, чтобы заменить старый обработчик обновления, который мог не запускать приложение после замены. Настройки хранятся отдельно.
